# Node Research: Branches

An add-on for Node Research that trades the floating physics bubbles for a tidy tree growing from left to right, like the vanilla research screen.

- Each project is a card with its icon, name, cost and progress inside it, instead of a bubble with text hanging underneath.
- Foundations and starting projects sit on the left, and each branch fans out to the right from the research it builds on.
- Everything a project needs sits to its left; long fans of follow-ups wrap into a compact grid.
- The All view shows each era as its own block, from Animal on the left to the latest era on the right.
- Lines between eras appear when you select a project at either end, keeping the tree readable.
- Everything else is Node Research as usual: eras, fog of war, expanding and collapsing, the queue, search and the side panel.
